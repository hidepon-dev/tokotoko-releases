# キャラクターパッケージ（`.toko` / `.zip`）制作・配布ガイド 🐾

[English](CHARACTER_PACKAGE.md) | **日本語**

このドキュメントでは、自作したオリジナルキャラクターに**名前・肩書（ロール）・ひとことセリフ・多言語設定**を添えて1つのファイルにまとめ、デスクトップマスコット「TokoToko」へ簡単にインポート・配布できる**オープンキャラクターパッケージ（`.toko` / `.zip`）**の作り方を解説します。

---

## 1. キャラクター登録の3つの形式

TokoToko のキャラクタースロット（Slot 1 〜 Slot 4）には、以下の3種類のファイルをドラッグ＆ドロップで登録できます。

| 形式 | 拡張子 | 用途・特徴 |
| :--- | :--- | :--- |
| **単体スプライト画像** | `.png` / `.webp` | 画像1枚だけを素早く登録したい場合に最適（👉 [スプライトシート仕様ガイド](SPRITE_SPEC.ja.md)）。 |
| **オープンパッケージ** | **`.toko` / `.zip`** | **【本ガイドの対象】** スプライト画像と `manifest.json`（名前・肩書・セリフ等）を標準 ZIP 圧縮した、クリエイター向けのオープン配布形式。 |
| **公式キャラクターパッケージ** | `.tokochar` | TokoToko 公式から配布される専用パッケージ形式。オープンパッケージと同様にスロットへドラッグ＆ドロップするだけで登録できます。 |

---

## 2. パッケージの基本構成（`.toko` / `.zip`）

オープンパッケージは、以下の2つのファイルを**フォルダに入れず（フラットな状態で）直接 ZIP 圧縮**したアーカイブです。  
拡張子は `.zip` のままでも、`.toko` にリネームしてもどちらでも同じように読み込めます。

```text
my_character.toko (または my_character.zip)
├── manifest.json       # キャラクター情報定義ファイル (必須 / UTF-8)
└── sprite.webp         # スプライトシート画像 (必須 / sprite.png も可)
```

### パッケージの制限事項
安全性と超軽量な動作を維持するため、以下の制限が設けられています。
- **パッケージ最大サイズ**: 展開後の合計サイズが **20 MB 以内**
- **最大ファイル数**: アーカイブ内のファイル数が **20 個以内**
- **フラット構造**: サブディレクトリ（フォルダ階層）や相対パス（`..`）を含めないでください。2つのファイルを選択して直接 ZIP 圧縮してください。
- **スプライト画像規格**: アスペクト比 **8:11**（横8コマ × 縦11行）、推奨および**最大解像度は 2048 × 2816 px** です。詳細は [スプライトシート仕様ガイド](SPRITE_SPEC.ja.md) を参照してください。

## 3. `manifest.json` の書き方

文字コードは **UTF-8** で作成してください。

### 3.1 基本サンプル
```json
{
  "id": "my_original_chara",
  "name": "コハク",
  "version": "1.0.0",
  "author": "Your Name",
  "role": "Navigator",
  "statusText": "今日も楽しくコーディングしようね！",
  "spriteFile": "sprite.webp"
}
```

### 3.2 多言語（日本語 / 英語）対応サンプル (`i18n`)
`i18n` ブロックを追加すると、TokoToko 本体の表示言語（日本語 `ja` / 英語 `en`）を切り替えた際に、カード上の名前・肩書・セリフも自動的に切り替わります。

```json
{
  "id": "my_original_chara",
  "name": "コハク",
  "version": "1.0.0",
  "author": "Your Name",
  "role": "Navigator",
  "statusText": "今日も楽しくコーディングしようね！",
  "spriteFile": "sprite.webp",
  "i18n": {
    "en": {
      "name": "Kohaku",
      "role": "Navigator",
      "statusText": "Let's enjoy coding together today!"
    }
  }
}
```

### 3.3 フィールドリファレンス

| キー | 型 | 必須 | 初期値 / 省略時 | 説明 |
| :--- | :--- | :---: | :--- | :--- |
| `id` | `string` | **必須** | — | キャラクター固有の識別子（半角英数字・アンダースコア推奨）。キズナ度（累計稼働時間）の記録キーとして使用されます。 |
| `name` | `string` | **必須** | — | スロットカードに表示されるキャラクター名。 |
| `version` | `string` | 任意 | `"1.0.0"` | パッケージのバージョン表記。 |
| `author` | `string` | 任意 | `""` | 制作者・クリエイター名。 |
| `role` | `string` | 任意 | `"Custom"` | スロットカードに表示される肩書・ロール（例: `"Navigator"`, `"Healer"` など）。 |
| `statusText` | `string` | 任意 | `""` | スロットカードのティッカーに流れるひとことセリフ。 |
| `spriteFile` | `string` | 任意 | `"sprite.webp"` | 同梱したスプライト画像のファイル名。省略時はアーカイブ内の `sprite.webp` または `sprite.png` を自動検出します。 |
| `i18n` | `object` | 任意 | `null` | 言語コード（`"ja"`, `"en"`）ごとの表示オーバーライド設定（`name`, `role`, `statusText` を指定可能）。 |

> 💡 **キズナ度（Kizuna）の引き継ぎについて:**  
> TokoToko はキャラクターと一緒に過ごした時間を `id` ごとに記憶しています。同じ `id` を持つパッケージであれば、一度スロットから外して別のスロットに登録し直しても、これまでのキズナランク（累計時間）がそのまま引き継がれます。

## 4. パッケージの作成手順

### 🍏 macOS の場合
1. 作業用フォルダ内に `manifest.json` と `sprite.webp`（または `sprite.png`）を用意します。
2. フォルダ自体ではなく、**中の2つのファイルを直接選択**して右クリックし、**「2項目を圧縮」** をクリックします（またはターミナルで以下を実行します）：
   ```bash
   zip my_character.toko manifest.json sprite.webp
   ```
3. 生成された `.zip`（または拡張子を `.toko` に変更したファイル）で完成です。

### 🪟 Windows の場合
1. 作業用フォルダ内の `manifest.json` と `sprite.webp`（または `sprite.png`）の **2つのファイルを選択**します。
2. 右クリックして **「ZIP ファイルに圧縮する」**（または「送る」→「圧縮 (zip 形式) フォルダー」）を選択します。
3. 必要に応じて拡張子を `.toko` に変更すれば完成です（`.zip` のままでも利用可能です）。

---

## 5. TokoToko へのインポート方法

1. デスクトップ上のマスコット（またはトレイアイコン）を右クリックし、**`⚙️ System Core...`** を開きます。
2. **「Character Slots」** タブを開きます。
3. **Slot 1 〜 Slot 4**（Slot 0 は Toko 固定枠です）のいずれかのカード枠内に、作成した `.toko` / `.zip` ファイル（または公式配布の `.tokochar` ファイル）を**ドラッグ＆ドロップ**します。
4. カード上の **「ATTACH」** ボタンを押すと、デスクトップ上のマスコットが切り替わります！
