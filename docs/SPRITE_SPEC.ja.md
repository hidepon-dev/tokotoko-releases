# 自作キャラクター制作・スプライトシート仕様ガイド 🐾

このドキュメントでは、デスクトップマスコット「TokoToko」に自作のオリジナルキャラクターを登録するための**スプライトシート（画像）規格**と**登録手順**を解説します。

TokoToko は、規格に沿って配置された画像ファイルを1枚用意するだけで、自律歩行や多彩なリアクションアニメーションを画面上で動かすことができます。

---

## 1. 基本画像規格

| 項目 | 仕様 | 備考 |
| :--- | :--- | :--- |
| **ファイル形式** | **PNG** または **WebP** | アルファチャンネル付き（透過背景） |
| **全体画像解像度** | **幅 2048 px × 高さ 2816 px** | 横8コマ × 縦11行 |
| **1コマあたりのサイズ** | **幅 256 px × 高さ 256 px** | 正方形 |
| **コマ構成** | **8 コマ / 1行**（全11行、計88コマ） | 左から右へループ再生 |
| **カラープロファイル** | sRGB | 透過処理を推奨 |

> 💡 **推奨設定:**  
> ドット絵やイラストの鮮明さを保ち、かつメモリ消費を抑えるため、**透過WebP（ロスレス）** または **透過PNG** での書き出しを推奨します。

---

## 2. アニメーション行（Row）構成とアクション定義

スプライトシートは縦に **11行（Row 00 〜 Row 10）** で構成されています。  
各行は左端（Col 0）から右端（Col 7）までの **8コマで1つのループモーション** を表現します。

```text
+--------+--------+--------+--------+--------+--------+--------+--------+
| Col 0  | Col 1  | Col 2  | Col 3  | Col 4  | Col 5  | Col 6  | Col 7  |
+--------+--------+--------+--------+--------+--------+--------+--------+
| Row 00 : アイドル待機 (idle)                                           |
| Row 01 : 右歩行ループ (running-right)                                  |
| Row 02 : 左歩行ループ (running-left)                                   |
| Row 03 : 挨拶・ピース (waving)                                         |
| Row 04 : 歓喜ジャンプ (jumping)                                        |
| Row 05 : 落胆・ため息 (failed)                                         |
| Row 06 : 髪かきあげ・待機 (waiting)                                     |
| Row 07 : 思索・ひらめき (running)                                      |
| Row 08 : 空中ホログラム操作 (review)                                   |
| Row 09 : びっくり・胸なでおろし (surprised)                            |
| Row 10 : 退屈・おねむ (bored)                                          |
+-----------------------------------------------------------------------+
```

### 各行のアクション詳細

| 行番号 | アクション識別子 (`action`) | 内容・仕草 | 主な発火トリガー |
| :--- | :--- | :--- | :--- |
| **Row 00** | `idle` | 静かな呼吸、まばたき | 通常の立ち止まり待機状態 |
| **Row 01** | `running-right` | 右方向への歩行・走り | 自律移動（右へ歩くとき） |
| **Row 02** | `running-left` | 左方向への歩行・走り | 自律移動（左へ歩くとき） |
| **Row 03** | `waving` | 笑顔で手を振る、ピースサイン | アイドル中のランダム行動 / 起動時 |
| **Row 04** | `jumping` | 歓喜のジャンプ、飛び跳ね | 左クリック / コマンド成功時 (`Exit 0`) |
| **Row 05** | `failed` | 焦り、落胆、ため息 | コマンド失敗時 (`Exit != 0`) / エラー発生時 |
| **Row 06** | `waiting` | 耳元の髪をかきあげる、ポーズ変更 | 長時間立ち止まり時 / 入力待機 |
| **Row 07** | `running` | 腕を組んで思索 〜 ひらめき指立て | プロンプト送信直後 / AI思考中 |
| **Row 08** | `review` | 空中にホログラムを出してタイピング | ビルド実行中 / コード生成ストリーミング中 |
| **Row 09** | `surprised` | 驚いてビクッとする、胸をなでおろす | 割り込み通知 / メール受信 / 予期せぬイベント |
| **Row 10** | `bored` | ぼんやり、あくび、居眠り | 長時間PC操作がないとき |

## 3. 作画時のポイント・注意点

1. **接地位置（ベースライン）を揃える**
   * 各コマ（256×256px）の中で、足の接地位置が上下にズレないように揃えておくと、アニメーション再生時や歩行時にガタつきません。
2. **ループの滑らかさ**
   * 各行の 8コマ（Col 0 〜 Col 7）は、Col 7 の次に Col 0 へスムーズに繋がるループアニメーションとして描画してください。
3. **簡易制作（最小構成で作りたい場合）**
   * すべての行（11行分）を完全に描き分けるのが大変な場合は、**Row 00（待機）、Row 01（右歩き）、Row 02（左歩き）** をまず作成し、他の行にはひとまず Row 00 のコマをコピーして埋めておく形でも動作します。

## 4. TokoToko への登録方法

制作したスプライトシートは、アプリ内からドラッグ＆ドロップで簡単に登録できます。

1. デスクトップ常駐中のマスコットを右クリックし、**「設定」** を開きます。
2. 左メニューから **「Character Slots」** タブを選択します。
3. 空いているスロットカード（Slot 2 〜 Slot 5）の枠内に、作成した画像ファイル（`.png` または `.webp`）を**ドラッグ＆ドロップ**します。
4. キャラクターの名前を入力して保存します。
5. カードの **「Switch」** ボタンを押すと、マスコットが自作キャラクターに切り替わります！
