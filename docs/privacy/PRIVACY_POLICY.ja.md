# TokoToko プライバシーポリシー

最終更新日: 2026年10月29日

TokoToko（以下「本アプリケーション」）は、hidepon によって開発・運営されている超軽量デスクトップマスコットです。私たちは利用者の皆様のプライバシーを尊重し、保護することに全力で取り組んでいます。本プライバシーポリシーでは、本アプリケーションの使用時における情報の取り扱いについて説明します。

## 1. 情報の収集と保存について
- **個人情報の不収集:** 本アプリケーションは、氏名・メールアドレス・IPアドレス等の個人を特定できる情報（PII）、または機密性の高い個人データを一切収集、追跡、記録、外部送信しません。
- **完全ローカル動作:** マスコットの描画アニメーション、ローカルIPC通信（Unixドメインソケット / 名前付きパイプ）、キャラクターパッケージのインポートなどの主要機能は、すべてお使いのPC（ローカル環境）上でのみ完結して動作します。
- **ローカル設定・データ保存:** アプリケーションの設定、キャラクター構成、および行動統計台帳は、すべて端末のユーザープロファイル直下（macOS/Linux: `~/.tokotoko/`、Windows: `%USERPROFILE%\.tokotoko\`）に保存され、外部サーバーやクラウドサービスへアップロードされることは一切ありません。
- **ブラウザ拡張機能・IPC連携における通信:** 任意の外部連携ツールやブラウザ拡張機能（TokoToko Chrome Extension 等）との通信は、標準入出力（stdio）およびローカル名前付きパイプ／Unixドメインソケットを介して、**同一マシン内でのみ完全ローカルに行われます**。ブラウザの閲覧履歴、チャット入力内容（プロンプト）、メール本文、その他の個人データが収集、記録、外部送信されることは一切ありません。
- **テレメトリ・解析ツールの不使用:** 本アプリケーションには、行動追跡コード、テレメトリ収集、利用状況解析（アナリティクス）ツール等は一切組み込まれていません。

## 2. 第三者提供およびネットワーク通信について
- **バックグラウンド通信なし:** 通常の動作中、本アプリケーションがインターネットを介して外部サーバーと通信を行うことはありません。
- **手動アップデート確認:** 利用者が設定画面（System Core）の「Check for Updates」ボタンを明示的にクリックした場合に限り、最新バージョンの有無を確認するために GitHub Releases の公開 API（`https://api.github.com/repos/hidepon-dev/tokotoko-releases/releases/latest`）へ読み取り専用の HTTPS リクエストを行います。この確認処理において、個人情報や端末識別情報が送信されることはありません。
- **データの第三者提供なし:** 本アプリケーションは、利用者のいかなるデータを第三者に販売、交換、または提供することはありません。
